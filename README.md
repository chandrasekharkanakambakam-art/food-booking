#  Food-Booking Application

A responsive and user-friendly Food Booking Application built using **React.js and Tailwind CSS**. Users can explore food items, browse menus, add food to their cart, place orders, and manage their bookings.

##  Features

-  Responsive Home Page
-  User Login and Registration
-  Browse Food Items
-  Food Menu with Categories
-  Search Food Items
-  Add to Cart and Remove from Cart
-  Increase and Decrease Food Quantity
-  Place Food Orders
-  My Bookings / My Orders
-  Cancel Orders
-  Responsive Design for Mobile and Desktop

## Installation and Setup

### 1. Clone the repository

git clone https://github.com/chandrasekharkanakambakam-art/food-booking.git

### 2. Navigate to the project folder
cd food-booking

### 3. Install dependencies

npm install

### 4. Start the development server

npm run dev

## 5. Open in browser

http://localhost:5173
